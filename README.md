# Flip Two ─ 次、なにする？

カップルで「次、なにする？」を決めるカードアプリ。

## できること

- **ふたりで選ぶ**: 5枚配って、それぞれこっそり「あり／なし」（スワイプでもOK）→ せーので答え合わせ → ふたりとも「あり」から決定（複数ならルーレット）
- **おまかせ**: 1枚めくってすぐ決める。拒否権でひとり1回引き直せる
- 決まったら、そのまま記録画面へ（写真・ふたり分のひとこと・やった！）
- 場所・予算・時間・時間帯・季節で絞り込み。季節は日付から自動判定（手動でも選べる）
- **今回だけのお題**: 出る確率をスライダーで 10〜90%
- **よく変えるルールはホームでワンタップ**: 拒否権／相手の答えを隠す／やったお題も出す
- **AIでお題をまとめて追加**: 今あるお題と重ならないプロンプトをコピー → AIの答えを貼るだけ（同じ・似ているお題は自動で外れる）
- **ふたりで同期（あとから使える）**: Firebase を設定すると、QRコードで招待してふたりのスマホでアルバム・お題・設定を共有できる。未設定なら1台で動き、画面にも出ない
- **ホーム画面アプリ**: ホーム画面に追加して使える。オフラインでも動く
- **バックアップ**: 記録・写真・設定を1ファイルに書き出し／読み込み

公開の準備（と、あとで共有したくなったときの手順）は **SETUP.md** を見てください。

## 動かし方

Node.js 20 以上が必要。

```bash
npm install
npm run dev          # 開発サーバー（http://localhost:5173）
npm test             # ゲームロジックのテスト
npm run build        # dist/ に通常の Web アプリとして出力
npm run build:artifact  # claude.ai のお試しページ用の1枚の HTML を dist-artifact/ に出力（同期なし）
node test-sync/server.mjs & npx vite build --mode fakesync  # 同期の動作確認用（Firebase の代わりにローカルの仮サーバーを使う）
```

スマホで試すときは `npm run dev -- --host` で起動し、同じ Wi-Fi のスマホから表示された URL を開く。

## ファイル構成

```
src/
  data/topics.ts      内蔵お題 422枚（27カテゴリ）。末尾に足せばお題を増やせる。外すときは RETIRED に本文を書く
  lib/types.ts        型
  lib/deck.ts         絞り込み・重み付き抽選（今回だけのお題の確率もここ）
  lib/aiImport.ts     AIでまとめて追加（プロンプト作成・答えの読み込み・重複チェック）
  lib/logic.test.ts   テスト
  lib/storage.ts      端末内保存（localStorage + 写真は IndexedDB）
  screens/            画面（Home / Pair=ふたりで選ぶ / Draw=おまかせ / Pages / AiAdd / SyncPanel / Backup）
  sync/               同期（config.ts に Firebase の設定を貼る、sync.ts が本体、useSync.ts が画面とのつなぎ）
  ui/                 共通部品・表示用ラベル・演出（motion.tsx）
  index.css           デザイン（色・フォントは先頭の :root にまとめてある）
```

## データの保存

- 同期していないとき: 記録・写真・設定は、使っているブラウザの中だけに保存される
- 同期しているとき: 加えて Firebase（Firestore）の rooms/{招待コード} に保存され、ふたりのスマホで共有される
- 条件の絞り込みだけは、それぞれのスマホごと
